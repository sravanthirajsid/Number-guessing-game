# Number-guessing-game

# Number Guessing Game

A simple Python command-line game where the computer randomly selects a number between 1 and 100, and the player tries to guess it.

## Technologies Used

 Python 3
 'random' module
 Command Line / Terminal
 VS Code

# Setup Instructions

# 1. Install Python

Install Python 3 on your computer.

# 2. Clone the Repository

Open your terminal and run:

'''bash
git clone YOUR_GITHUB_REPOSITORY_LINK
'''

### 3. Open the Project
'''bash
cd number-guessing-game
'''

# 4. Run the Program

'''bash
python number_guessing.py
'''

If your system uses `python3`:

'''bash
python3 number_guessing.py
'''

# 5. Play the Game

The computer will select a random number between 1 and 100.

Enter your guesses until you find the correct number.

Example:

'''text
Guess a number between 1 and 100: 50
Too high! Try again.

Guess a number between 1 and 100: 25
Too low! Try again.

Guess a number between 1 and 100: 37
Correct! You guessed the number.
'''
